# Project Plan

Create a native MacOS desktop application for editing Markdown files.

This looks like a very helpful SwiftUI project which might do a lot of the grunt work for us :

https://github.com/Pallepadehat/MarkdownEditor


## Phase One Features

- Open/edit/save Markdown files
- Syntax highlighting
- Live preview
- Regular MacOS keyboard shortcuts
- Normal MacOS menu options like 'Open recent'
- Undo/redo
- Settings for font, font size, tab width, etc.

## Phase Two Features

- Inline image support
- 'AI' text prediction, 'editing' (as in highlight text and ask 'Can you make this sound more friendly')
- Support for calling agent skills (as in the SKILL.md files from claude/codex/etc)
